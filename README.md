# Jalo Games

> Small is the gate, and narrow the road. — the studio site at [jalogames.fi](https://jalogames.fi)

Single-page presence for **Jalo Games Oy** — a founder-led independent game
studio in Helsinki, Finland. Original worlds, premium craft, built to last.
Now building **Grace Run**.

## Stack

- Next.js 16 · React 19 · Tailwind CSS 4
- Lenis smooth scroll, custom cursor, film grain, scroll-driven reveals
- Deployed on Vercel

## Develop

```bash
npm install
npm run dev    # http://localhost:3000
npm run build  # production build
```
